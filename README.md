## Quick Start

Install dependencies:
pip install duckdb psycopg2-binary requests dbt-duckdb pandas

Start source systems:
make up

Generate 18 months of data:
make seed

Run full pipeline (EL + dbt):
make run

That is it. One command runs everything end to end.

## What Was Built

### Extract-Load (el/)

extract_postgres.py - Pulls 6 Postgres tables incrementally using updated_at watermarks. Handles soft deletes (deleted_at) and hard deletes via users_cdc two-pass approach. Upserts into DuckDB.
extract_billing_api.py - Paginates all 4 REST API endpoints. Converts cents to dollars, epoch to datetime. Unnests invoice line items.
extract_usage_files.py - Reads JSONL files, deduplicates by event_id, handles schema drift, tracks file mtime for late arrivals.
snapshot_users.py - DIY hard delete detection without users_cdc, snapshot diff approach.

### dbt Models (transform/)

Staging - 11 stg_* models - Clean, cast, dedupe, 1:1 with sources
Intermediate - int_subscription_periods - Point-in-time subscription state reconstruction
Intermediate - int_billing_account_link - Billing customer to account recovery (direct + domain match)
Mart - fct_revenue - Revenue per account x month with MRR movement
Mart - fct_reconciliation - Billed vs collected vs expected reconciliation
Mart - dim_accounts - SCD2 account history from subscription_changes

## CDC Loop

make seed          - full load
make run           - baseline pipeline run
make tick DAYS=14  - advance simulated clock
make run           - incremental load, only new/changed rows
make run           - re-run with no tick, nothing changes (idempotent)

All three scenarios verified and passing.
